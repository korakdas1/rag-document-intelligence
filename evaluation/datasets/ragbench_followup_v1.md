# ragbench_followup_v1

Small conversational follow-up set. **Not** a public leaderboard.

- **Documents:** `evaluation/corpus/followup/willow_and_ash.md` (project-owned) plus existing `error_codes.md` for topic-switch / filter cases
- **Kept separate** from `evaluation/corpus/` top-level files so ragbench_v1 ingest stays unchanged
- **Purpose:** score query rewriting (entity preservation, rewrite-required accuracy), not chat quality
- **License:** project-owned synthetic text

Independent `ragbench_v1` questions remain valid without conversation history.
