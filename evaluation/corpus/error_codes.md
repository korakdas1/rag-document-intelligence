# Runtime Error Codes

Synthetic operator handbook for a research cluster.

## Connection failures

ERR_CONNECTION_REFUSED is returned when a TCP handshake is rejected by the remote host.
Retrying without checking the listener usually repeats the same error.

## Experiment identifiers

Experiment identifier XRQ-917-BETA must be quoted in lexical queries because hyphens are operators in some search engines.
The identifier is unique in this corpus on purpose.
