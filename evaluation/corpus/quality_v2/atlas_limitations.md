# Atlas analysis memorandum: limits and open audit items

Record ARP-L, 14 October 2024. Synthetic analysis note, maintained independently of the methods memorandum.

Atlas does not evaluate handwritten annotations in the manual margins.
The source set contains typed text with explicit section headings. A successful lookup in that set does not establish optical character recognition quality or the ability to read a technician's handwriting. The archive's clean text is a study boundary, not a claim that engineering records are always clean.

Atlas uses authored manuals and excludes customer documents from its study corpus.
The result therefore cannot be presented as measured accuracy on a customer's private library. Customer documents could contain different vocabulary, formatting, and revision conventions. The study offers a controlled comparison of failure modes rather than a production service guarantee.

For Atlas review batch R9, the analysis memorandum allocates 36 cases to the independent audit pool.
This is the same batch and pool definition named in the methods memorandum. Neither allocation is authoritative over the other, and the discrepancy is unresolved. The difference is not a count of candidate passages or a later increase approved by the chair. Both source statements must remain visible in a report about the allocation.

The diagnostic label ARP_ALIAS_WARN marks a possible duplicate name that still needs inspection. It is not the blocking collision error described by the release note. A warning may be cleared after two paths are shown to represent the same revision. A confirmed path collision needs a different response.

The study did not measure hardware power, billing cost, model parameter count, or diagnostic sensitivity on medical cases. Retrieval timings cannot be used to infer those absent quantities.
