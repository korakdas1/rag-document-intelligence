# Meridian Transit Sensor Study: corridor brief

Record MTS-B, 12 March 2024. Original synthetic planning note for a fictional transit instrumentation study.

The Meridian study measures platform departures without collecting face images.
It combines an edge counter with an observer's event sheet. The pilot is intended to improve the interpretation of station activity, not to identify individual riders. A departure event is not the same thing as a fare transaction or a complete passenger journey.

The study uses the Stone Arch platform on corridor C. A maintenance walkway beside the platform is outside the counting boundary. Staff mark that boundary on the setup diagram because equipment crews can otherwise appear to be passengers. The pilot operates while ordinary services continue, with an observer available to flag unusual movements.

The Meridian brief assigns Tessa Lorn responsibility for corridor C inspection handoff in April 2024.
The protocol contains an independently maintained assignment for the same duty and month. Neither document has been designated authoritative for this handoff. The team kept both records while waiting for a joint sign-off; a later instrument release does not settle a staffing disagreement.

The station manager can suspend collection when maintenance changes the walking route. Suspension is an operational protection, not a finding that the sensor is inaccurate. A valid comparison needs the route, counter configuration, and observer coverage to be known together. Summaries should name the corridor and interval instead of calling every station count a Meridian baseline.

The archive contains engineering observations rather than passenger billing records. It cannot supply individual fares, home addresses, or travel histories. Those fields were not part of the collection plan.
