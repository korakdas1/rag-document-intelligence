# Atlas archive release note: revision 2

Record ARP-R2, 25 October 2024. Synthetic release note for the fictional manual-retrieval study. This document establishes authority only for the fields it explicitly changes.

## Revision policy

Atlas keeps retired manuals searchable as historical sources, but does not treat them as current instructions.
The archive labels each passage with its source revision and status. A user investigating an old maintenance action can therefore retrieve the instruction that applied at that time. A user asking for the present procedure should receive the current source. Deleting every retired manual would make current queries easier while making the archive less useful for historical work.

The release package includes both current and retired sources in the inventory. Their status is a retrieval condition, not a decoration added after answer generation. A summary that quotes an old instruction without its status can be misleading even if every quoted word is present in a source. The revision policy is designed to preserve evidence rather than to erase inconvenient alternatives.

## Final acceptance gate

Atlas's final evidence-recovery threshold is 87%, superseding revision 1's proposed 84% gate.
This changes the acceptance decision for the defined worksheet. It does not claim that a particular run achieved the gate, and it does not redefine the measured evidence-recovery field. Old decisions remain associated with their old gate so that reviewers can reconstruct why they were made. Applying the final gate to an old result creates a new decision entry.

## Collision handling

ARP_ALIAS_CLASH means that one Atlas source path has been assigned to two different manual revisions.
This is a blocking import error because a path-only citation could otherwise identify two incompatible texts. Operators preserve both candidate files and correct the manifest mapping before retrying. They must not resolve the collision by keeping whichever file was encountered last. The softer warning label in the analysis memo describes a suspicion, not this confirmed error.

## Review records

Atlas retains reviewer comments for 30 days after the release review closes.
This interval concerns the working comments, not the immutable source manifest or the rollback snapshots described in the operations report. The custodian checks for an explicit hold before routine expiration. Deleting a local comment export is not permission to remove the signed decision record.

The review package links the final gate, the source inventory, and unresolved audit notes. The release does not reconcile the competing R9 audit-pool allocations. Neither allocation becomes correct by proximity to a signed notice. Staff must obtain a joint allocation record if that disagreement needs to be resolved for later work.

This release changes no hosted application's model, prompt, or retrieval settings. Its fictional numbers and procedures belong to the authored study. They should not be reported as a performance baseline for the repository that stores these documents.
