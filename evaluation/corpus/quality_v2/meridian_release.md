# Meridian instrument release notice

Record MTS-R2, signed 7 May 2024. This notice changes named instrument fields and closes the amplitude incident. It does not assign priority to independent staffing or event-count ledgers.

## Firmware and acceptance

The Meridian pilot release uses firmware MTS-2.4.
The firmware identifier belongs to the instrument image, while the protocol revision identifies the measurement procedure. A technician must record both before comparing two runs. Reinstalling the same image after a hardware replacement is not a new protocol revision. Conversely, a revised acceptance rule can apply without a new instrument binary.

Meridian's final minimum departure-detection score is 0.83, superseding draft D's proposed 0.80.
The final rule applies to the defined matched-event fraction. It does not alter the label window or turn unstaffed observations into validated examples. Old acceptance decisions remain in the archive with the draft rule named explicitly. A current decision must use the final rule and the same documented denominator.

## Authorization

Meridian remains approved for an observed pilot but is not approved for automatic dispatch control.
The station controller must continue to use the existing operating procedure. The pilot counter may inform an engineering review, but it cannot independently command a departure or change a platform signal. The presence of a release identifier on the instrument does not expand this authorization boundary.

The operator checks the firmware identifier after a power interruption and confirms that the boundary diagram is still posted. If maintenance moves the counter, collection pauses until the calibration walk is repeated. This procedure reduces configuration uncertainty; it does not establish a safety case for unattended control.

## Incident closure

Meridian's final inspection found a loose mounting bracket, superseding the preliminary clock-drift explanation for the amplitude drop.
The counter's clock remained within the recorded alignment tolerance during the affected interval. Movement at the bracket changed the view of the exit line, and securing it removed the amplitude change under the same movement check. The conclusion concerns the April incident, not every missing event in the sample.

The incident note remains available because it preserves the initial observations and response. Readers should distinguish the corrected causal hypothesis from the unrelated disagreement over invalid-ping counts. This notice does not reconcile the 18 April outage ledgers or the competing inspection-handoff assignments. Both disagreements still require their own joint sign-off.

## Handover

Operators export the instrument image identifier, the setup photograph, and the validation worksheet together. A worksheet without the image identifier is incomplete even if its detection score exceeds the gate. The release archive records no fare price, complete trip-duration distribution, or subgroup accuracy estimate for wheelchair users. Those cannot be reconstructed from the acceptance score.
